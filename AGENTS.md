- Отвечай максимально плотно: минимум слов, максимум смысла.
- Новые примеры compose/config/scripts для inference engines добавляй в этот репозиторий.
- Каждый пример клади в отдельную папку с README и нужными compose/config/scripts рядом.
- В новом или изменяемом `docker-compose.yaml` записывай длинный service `command` через `command: >-`: один флаг на строку, без backslash-продолжений. Длинный список `- --flag` запрещён.
- Проверяй `docker compose config --quiet` и итоговый argv из `docker compose config --format json`; пробелы по краям argv запрещены.

## Контракт Compose

- Готовые опубликованные образы. Локальная сборка требует отдельного решения пользователя; автоматический build при запуске запрещён.
- Reasoning включён по умолчанию, уровень medium при поддержке. Проверяй фактические defaults модели, движка и chat template; ограничения фиксируй в README.
- SMG: 30001. vLLM/SGLang: 30000 во внутренней сети Docker. Метрики и телеметрия: 9234.
- Основа — high throughput. Low-latency пресеты исключены; флаги проверяй для модели, оборудования и версии движка.
- Перед KV-cache offloading проверяй issues модели, cache tiers и релиза. Три варианта: база без offloading; расширение базы с RAM; отдельное расширение базы с RAM + SSD.
- Константы и пути задавай в Compose. Громоздкие env-файлы запрещены; исключения — безопасность. Значения, используемые более трёх раз, переиспользуй через объявление внутри Compose.
- Эксперименты: локальный restart override "no". Публикуемый default: unless-stopped.
