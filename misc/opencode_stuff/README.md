# OpenCode: разрешения для контекстных операций

`permissions.json` — переносимый фрагмент пользовательского конфига. Содержит только `permission` и настройки разрешений агентов `build` / `general`; модели, провайдеры, токены и локальные пути отсутствуют.

## Подключение

1. Сохрани резервную копию `~/.config/opencode/opencode.json` (или используемого `opencode.jsonc`).
2. Перенеси `permission` и `agent` из `permissions.json` в существующий конфиг. Объедини настройки существующих агентов, сохрани их модели, prompts и остальные поля. Если разрешения уже настроены, проверь конфликтующие правила.
3. Сохрани порядок правил Bash: уточняющие `ask` расположены после общих `allow`. Перезапусти OpenCode.

При создании нового конфига можно использовать содержимое `permissions.json` целиком. Замена действующего конфига целиком удалит остальные настройки.

## Что разрешено

- Чтение и контекст: `ls`, `cat`, `head`, `tail`, `rg`, `find`, `diff`, `du`, `date`, `which` и другие команды из списка; чтение Git.
- Создание: `mkdir`, `touch`, `mktemp`.
- Инструменты: `read`, `glob`, `grep`, `lsp`, `skill`, `webfetch`, `websearch`.
- У `build`: вопросы, список задач и сабагент `explore`.

Прочие Bash-команды требуют подтверждения. Отдельные `ask` предусмотрены для `find -delete/-exec`, ряда опций с побочными эффектами, перенаправлений `>` и чтения `.env` через `read`. Правки через `edit` у `build` / `general` и другие сабагенты у `build` требуют подтверждения.

## Границы

Это текстовые шаблоны разрешений; строгую изоляцию и отсутствие побочных эффектов они не гарантируют. Правило `.env` для `read` не ограничивает чтение через Bash. Создание файлов явно разрешено. Доступ к внешним каталогам, MCP и дополнительные инструменты зависят от остальных настроек. Наличие `allow` не включает недоступный инструмент.

Фрагмент подготовлен для синтаксиса OpenCode V1 (`permission` / `bash`), ранее проверенного на 1.18.23. На 2026-09-29 сверен с пользовательским конфигом источника. Совместимость с другими версиями отдельно не проверялась. Правила агентов Command Center могут дополнительно переопределять эти разрешения.
